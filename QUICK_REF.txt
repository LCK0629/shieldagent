# 🛡️ ShieldAgent - Quick Reference Card

## 📥 Installation (3 commands)

```bash
python -m venv venv
(Windows) .\venv\Scripts\Activate.ps1 || (Mac/Linux) source venv/bin/activate
pip install -r requirements.txt
```

## 🎓 Train Model (1 command)

```bash
python train.py --sample-size 100000
```

Creates:
- `models/fraud_model.pkl` - Trained XGBoost
- `models/metrics.json` - Performance metrics
- `data/reference_transactions.csv` - 300 samples

## 🚀 Launch Dashboard (1 command)

```bash
streamlit run streamlit_app.py
```

Opens: http://localhost:8501

## 🎯 Agent Decision Policy

```
Risk Score → Action
< 0.35     → PASS (allow)
0.35-0.70  → FLAG (monitor)
0.70-0.90  → ESCALATE (review)
≥ 0.90     → BLOCK (deny)
```
