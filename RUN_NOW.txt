ShieldAgent - Run Now
=====================

Project folder:

    shieldagent/

Recommended Windows run:

    Double-click START.bat

What START.bat does:

    1. Creates venv if it does not exist.
    2. Activates the virtual environment.
    3. Installs the main dependencies.
    4. Trains the model if models/fraud_model.pkl is missing.
    5. Starts the Streamlit dashboard.

Dashboard URL:

    http://localhost:8501


Manual Run
----------

Open a terminal in the shieldagent folder:

    cd shieldagent

Create and activate a virtual environment:

    python -m venv venv

Windows PowerShell:

    .\venv\Scripts\Activate.ps1

Windows cmd:

    venv\Scripts\activate.bat

macOS/Linux:

    source venv/bin/activate

Install dependencies:

    pip install -r requirements.txt

Train the model:

    python train.py --sample-size 100000

Start the dashboard:

    streamlit run streamlit_app.py

Open:

    http://localhost:8501


Optional FastAPI Backend
------------------------

After training, run:

    uvicorn app:app --reload

Open:

    http://localhost:8000

Useful endpoints:

    GET  /api/health
    GET  /api/metrics
    GET  /api/stream
    POST /api/predict


Generated Files
---------------

Training creates:

    models/fraud_model.pkl
    models/metrics.json
    data/reference_transactions.csv


Expected First Run Time
-----------------------

Dependency installation and model training may take a few minutes.
Later runs are faster because the virtual environment and trained model already exist.


Troubleshooting
---------------

Model not found:

    python train.py --sample-size 100000

Port 8501 already in use:

    streamlit run streamlit_app.py --server.port 8502

Need faster training:

    python train.py --sample-size 50000

Use all available rows from the selected KDD Cup 99 subset:

    python train.py --sample-size 0


Status
------

Ready to run once dependencies are installed and the model has been trained.
